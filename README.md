## MOVIE ANALYSIS SYSTEM

# 🎬 Pandas Movie Analysis System

A beginner-friendly movie analysis project built using Pandas in Python.

This project analyzes Bollywood movie data based on ratings, views, release year, genres, and popularity score while practicing important Pandas operations.

---

# 🚀 Features

✅ Show all movies
✅ Find highest rated movie
✅ Find oldest movie
✅ Find newest movie
✅ Find most watched movie
✅ Genre-wise movie analysis
✅ Calculate popularity score
✅ Sort movies by popularity

---

# 🛠️ Technologies Used

- Python
- Pandas

---

# 📊 Pandas Concepts Practiced

- DataFrame creation
- Filtering data
- Sorting values
- GroupBy operations
- Boolean indexing
- Creating new columns
- Data analysis operations

---

# 📌 Project Purpose

This project was created to practice core Pandas concepts by building a simple movie analysis system using a custom dataset.

Previously, I implemented a similar movie analyzer using NumPy, and this version focuses on understanding how Pandas DataFrames make data analysis and data handling more efficient and organized.
